## Ceejay Xiong – Portfolio

This is my personal portfolio website showcasing selected projects, case studies, and experiments across software engineering, product, and Web3. The site focuses on clear presentation, performance, and readable long‑form project writeups.

### Local Development

Run the development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

### Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- next/font (Inter)
